🚀 How to Run the Project

Follow these steps to run the portfolio on your computer.

1. Clone the Repository

git clone https://github.com/vratijain2412-beep/vratijain2412-beep.github.io.git

Replace the repository URL above with your actual repository URL if it is different.

2. Open the Project Folder

cd vratijain2412-beep.github.io

3. Open in VS Code

code .

4. Run the Website

Open index.html in your browser.

Alternatively, install the Live Server extension in VS Code, right-click index.html, and select Open with Live Server.

📸 Add Your Profile Photo

Place your photo in the project folder and name it:

profile.jpg

Make sure the filename matches the image path used in index.html.
